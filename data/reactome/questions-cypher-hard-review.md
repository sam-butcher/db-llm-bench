## 7. argmax

Among Homo sapiens pathways that directly contain at least twenty reaction-like events, which records the highest number of distinct input entities per directly contained reaction-like event? Give its name.

**Expected** (str):

```json

```

**cypher**

```cypher
MATCH (p:Pathway)-[:species]->(:Species {displayName:'Homo sapiens'})
MATCH (p)-[:hasEvent]->(e:ReactionLikeEvent)
WITH p, count(DISTINCT e) AS events
WHERE events >= 20
MATCH (p)-[:hasEvent]->(:ReactionLikeEvent)-[:input]->(i)
WITH p, events, count(DISTINCT i) AS inputs
ORDER BY 1.0 * inputs / events DESC
LIMIT 1
RETURN p.displayName
```

**sql**

```sql
WITH ev AS (
    SELECT he.DB_ID AS p, COUNT(DISTINCT he.hasEvent) AS events
    FROM Pathway_2_hasEvent he
    JOIN ReactionlikeEvent r ON r.DB_ID = he.hasEvent
    JOIN Event_2_species es ON es.DB_ID = he.DB_ID
    JOIN DatabaseObject sp ON sp.DB_ID = es.species
    AND sp._displayName = 'Homo sapiens'
    GROUP BY he.DB_ID
    HAVING COUNT(DISTINCT he.hasEvent) >= 20),
inp AS (
    SELECT he.DB_ID AS p, COUNT(DISTINCT ri.input) AS inputs
    FROM Pathway_2_hasEvent he
    JOIN ReactionlikeEvent_2_input ri ON ri.DB_ID = he.hasEvent
    GROUP BY he.DB_ID)
SELECT d._displayName
FROM ev
JOIN inp ON inp.p = ev.p
JOIN DatabaseObject d ON d.DB_ID = ev.p
ORDER BY inp.inputs / ev.events DESC
LIMIT 1;
```
