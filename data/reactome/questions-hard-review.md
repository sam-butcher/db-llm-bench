**cypher**

```cypher
MATCH (r:ReactionLikeEvent)-[:species]->(:Species {displayName:'Homo sapiens'})
MATCH (r)-[:input]->(i)
WITH r, count(DISTINCT i) AS inputs
WITH inputs, count(r) AS events
WITH collect({inputs: inputs, events: events}) AS rows, sum(events) AS total
UNWIND rows AS row
WITH row.inputs AS inputs, row.events AS events, total
ORDER BY events DESC, inputs
LIMIT 5
RETURN inputs, events, round(100.0 * events / total, 1) AS pct
```

```sql

grp AS (
    SELECT inputs, COUNT(*) AS events
    FROM per
    GROUP BY inputs)

FROM grp

## 6. reification

Among Homo sapiens reaction-like events, a disease entity may be recorded as standing in for the normal entity it replaces. How many distinct pairs of a disease entity and its normal entity are both Complexes that have no part in common — no component, member, candidate or repeated unit shared between them?

**Expected** (int):

```json
36
```

**cypher**

```cypher
MATCH (r:ReactionLikeEvent)-[:species]->(:Species {displayName:'Homo sapiens'})
MATCH (r)-[:entityFunctionalStatus]->(efs:EntityFunctionalStatus)
MATCH (efs)-[:diseaseEntity]->(de:Complex)
MATCH (efs)-[:normalEntity]->(ne:Complex)
WHERE NOT EXISTS {
    MATCH (de)-[:hasComponent|hasMember|hasCandidate|repeatedUnit]->(x)
    MATCH (ne)-[:hasComponent|hasMember|hasCandidate|repeatedUnit]->(x) }
WITH DISTINCT de, ne

```

**sql**

```sql
WITH parts AS (
    SELECT DB_ID AS whole, hasComponent AS part
    FROM Complex_2_hasComponent
    UNION
    SELECT DB_ID, hasMember
    FROM EntitySet_2_hasMember
    UNION
    SELECT DB_ID, hasCandidate
    FROM CandidateSet_2_hasCandidate
    UNION
    SELECT DB_ID, repeatedUnit
    FROM Polymer_2_repeatedUnit)

FROM (
    SELECT DISTINCT efs.diseaseEntity AS de, efs.normalEntity AS ne
    FROM ReactionlikeEvent_2_entityFunctionalStatus re
    JOIN EntityFunctionalStatus efs ON efs.DB_ID = re.entityFunctionalStatus

        SELECT 1
        FROM parts p1

The question says non-empty because 65 Reactome name lists carry a trailing empty string (e.g. RHOG's ["RHOG", "RhoG", ""]); the TypeDB export drops it as a data-entry artefact, so without the exclusion Neo4j and MySQL match 22 more entities to reference entities through the empty string (2111 and 2112) while TypeDB reports 2089. MySQL's default collation compares strings case-insensitively; joining the two name tables without BINARY returns 5217, because human names such as INS then match names such as Ins on reference entities of other species.

**cypher**

```cypher
CALL {
    MATCH (p:PhysicalEntity)-[:species]->(:Species {displayName:'Homo sapiens'})
    UNWIND p.name AS n
    RETURN n, p AS x, 'pe' AS k
    UNION ALL
    MATCH (r:ReferenceEntity)
    UNWIND r.name AS n
    RETURN n, r AS x, 're' AS k }
WITH n, collect(CASE WHEN k = 'pe' THEN x END) AS ps, collect(CASE WHEN k = 're' THEN x END) AS rs
WHERE n <> ''
AND size(ps) > 0
AND size(rs) > 0
UNWIND ps AS p
UNWIND rs AS r
WITH DISTINCT p, r
WHERE NOT (p)-[:referenceEntity]->(r)
RETURN count(DISTINCT p)
```

**sql**

```sql
WITH pesp AS (
    SELECT DB_ID, species
    FROM GenomeEncodedEntity
    WHERE species IS NOT NULL
    UNION ALL
    SELECT DB_ID, species
    FROM SimpleEntity
    WHERE species IS NOT NULL
    UNION ALL
    SELECT DB_ID, species
    FROM Cell_2_species
    UNION ALL
    SELECT DB_ID, species
    FROM Complex_2_species
    UNION ALL
    SELECT DB_ID, species
    FROM EntitySet_2_species
    UNION ALL
    SELECT DB_ID, species
    FROM Polymer_2_species),
hs AS (
    SELECT DISTINCT pesp.DB_ID
    FROM pesp
    JOIN DatabaseObject s ON s.DB_ID = pesp.species
    AND s._displayName = 'Homo sapiens'),
refs AS (
    SELECT DB_ID, referenceEntity
    FROM EntityWithAccessionedSequence
    WHERE referenceEntity IS NOT NULL
    UNION ALL
    SELECT DB_ID, referenceEntity
    FROM SimpleEntity
    WHERE referenceEntity IS NOT NULL
    UNION ALL
    SELECT DB_ID, referenceEntity
    FROM Drug
    WHERE referenceEntity IS NOT NULL)
SELECT COUNT(DISTINCT hs.DB_ID)
FROM hs
JOIN PhysicalEntity_2_name pn ON pn.DB_ID = hs.DB_ID
JOIN ReferenceEntity_2_name rn ON BINARY rn.name = BINARY pn.name
WHERE pn.name <> ''
AND NOT EXISTS (
    SELECT 1
    FROM refs
    WHERE refs.DB_ID = hs.DB_ID
    AND refs.referenceEntity = rn.DB_ID);
```

**cypher**

```cypher
MATCH (x)
WHERE toLower(coalesce(x.displayName, '')) CONTAINS 'ras'
OR any(v IN coalesce(x.name, [])
    WHERE toLower(v) CONTAINS 'ras')
